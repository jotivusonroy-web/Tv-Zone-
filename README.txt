RAJIB TV — updated build

This build automatically loads channels.json.
Real channel logos are resolved from the public iptv-org channel/logo database when available.
If a stream produces a fatal playback error in the browser, the site automatically hides that channel
and remembers it locally so it will not keep appearing as a broken channel.

Important: live-stream availability can vary by time, region, CORS, geo-blocking and source-server status.
A channel that fails in one network may work in another.
